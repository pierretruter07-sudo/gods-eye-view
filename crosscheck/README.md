# CrossCheck (backup of the assessment kit)

A safety copy of the working kit used to audit God's Eye View against
EUROCAE ED-153, OWASP ASVS 5.0 and ISO/IEC 42001: catalogues, rating
scripts, the CrossCheck app template, the ledger and plan builders.

This branch only backs the kit up. It is not wired into the app. The plan to
turn it into the standalone CrossCheck product is in the project doc
"God's Eye View and CrossCheck: two products".
