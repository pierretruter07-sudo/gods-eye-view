# Brand icons

The Digital Dynamics loop mark, cut from its black disc so it can sit on a
browser tab. Source: the DDG mark supplied on 22 Oct 2026 (brand guide v3.1,
"Glacier Glitch"). Used as the tab icon here and in DDG Greenlight.

| File | Use |
| --- | --- |
| `ddg-mark.svg` | Tab icon. Snow White mark on dark tab bars; navy-ink mark on light ones (`prefers-color-scheme`). |
| `ddg-mark-32.png` | Tab icon fallback, 32 px. |
| `favicon.ico` | Legacy fallback, 16 to 64 px. |
| `ddg-mark-180.png` | Apple touch icon. |
| `ddg-mark-192.png`, `ddg-mark-512.png` | Web app manifest sizes. |

The brand guide prefers the mark on its dark disc; the navy-ink light variant
exists only because a white knockout mark disappears on a light tab bar.
